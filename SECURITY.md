# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's **Report a vulnerability** button on the repository's Security tab rather than in a public issue. Include steps to reproduce and the impact you observed. We aim to acknowledge reports within 3 business days.

## Scope

This repository is a demo. It has no real accounts, payments or messaging; see "Limits of this demo" in the README. Reports about the public AI routes (`/api/ai/*`), the deployment configuration and anything that could expose secrets or run code are most useful.

The full security review of the current design is in [docs/security-review.md](docs/security-review.md).
